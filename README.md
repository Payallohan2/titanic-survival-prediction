# Titanic Survival Prediction 🛳️

This project applies **Machine Learning** techniques to predict passenger survival on the Titanic dataset.  
It demonstrates end-to-end workflow including:

- 📊 Data Collection & Preprocessing  
- 🔍 Exploratory Data Analysis (EDA)  
- 🤖 Model Building using Logistic Regression  
- 📈 Model Evaluation with accuracy metrics  

The notebook showcases how classical ML methods can be applied to real-world datasets, making it a great beginner-friendly project for learning data science and predictive modeling.

## Dataset
The dataset used is the **Titanic Dataset** available on Kaggle.  
Columns include passenger details such as age, sex, class, fare, and survival status.

## Tech Stack
- Python (NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn)  
- Kaggle Notebook Environment  

## Results
Achieved a baseline accuracy using Logistic Regression.  
Further improvements can be made by feature engineering and trying advanced models.
